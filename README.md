# -# 智慧行動電源電量與快充超時保護系統（NUCLEO-G474RE 期中專題）
精準掌握電量變化，滿 15 秒自動啟動涓流保護，確保充電安全。

## 1. 情境故事
現代人高度依賴行動電源，但若裝置長時間處於高壓快充狀態，容易導致電池過熱甚至膨脹。本專案模擬一款智慧行動電源，使用者可隨時監控電量，且系統會在持續充電達 15 秒後自動進入「涓流充電（安全模式）」，直到使用者重新插拔線材才會解除。

## 2. 替身對照
* 實際充放電電流 $\rightarrow$ 終端機鍵盤輸入（`-` 耗電，`+` 充電）
* 行動電源電量指示燈 $\rightarrow$ 開發板內建綠燈（PA5），依據電量多寡改變 PWM 亮度
* 重新插拔 Type-C 傳輸線 $\rightarrow$ 按下開發板藍色按鈕（B1）重置系統
* 涓流保護機制 $\rightarrow$ LED 降至最低微光，終端機印出 SAFE MODE 警告

## 3. 功能與驗收條件
* **電量控制**：在終端機輸入 `-` 電量扣 10%；輸入 `+` 電量加 10%，同步更新顯示。
* **PWM 亮度連動**：電量 100% 時綠燈最亮，0% 時熄滅，隨電量變化肉眼可見。
* **快充超時保護**：系統計時達 15 秒後，終端機顯示 `[SAFE MODE] 15s Reached! Trickle Charging Activated.`，且綠燈亮度強制降至 1（微光）。
* **中斷重置**：按下 B1 藍色按鈕後，電量瞬間恢復 100%，計時器歸零，解除安全模式。

## 4. 用到的技術
* GPIO Output (控制 LED 亮暗)
* EXTI 外部中斷 (按鈕觸發重置)
* LPUART 通訊與中斷接收 (與終端機進行指令互動)
* TIM 硬體定時器 (1ms 觸發與 15 秒精準倒數)
* PWM 軟體模擬 (透過 BSRR 暫存器控制 LED 佔空比)

## 5. 腳位表
* PA5 = LD2 (綠色 LED，顯示電量與涓流狀態)
* PC13 = B1 (藍色按鈕，觸發 EXTI 重置)[cite: 12]
* PA2 / PA3 = LPUART1 (ST-LINK VCP，通訊序列埠)[cite: 12]

## 6. 建置與執行
* 開發環境：STM32CubeIDE 
* 終端機設定：Baud Rate `115200`，`8N1`[cite: 12]
* 操作指令：游標點擊終端機畫面後，輸入 `-` 加 `Enter` (耗電)、`+` 加 `Enter` (充電)

## 7. 程式結構
* `main()` 迴圈：負責檢查 `update_ui_flag`，若有變化則透過 `printf` 更新終端機畫面與時間。
* `HAL_UART_RxCpltCallback`：(ISR) 接收鍵盤字元並存入 Ring Buffer 陣列中。
* `HAL_TIM_PeriodElapsedCallback`：(ISR) 每 1ms 觸發一次，控制 PWM 亮暗週期，並負責 15 秒的累加計時。
* `HAL_GPIO_EXTI_Callback`：(ISR) 偵測按鈕按下，重置電量與時間變數。

## 10. 已知限制
* 目前以終端機鍵盤輸入模擬充放電，未來若要商用需換成真實的 ADC 電壓/電流感測模組。
* 軟體模擬 PWM 佔用較多 Timer 中斷資源，若擴充多顆 LED，需改用硬體 PWM (如 TIM3 Channel) 實作。
